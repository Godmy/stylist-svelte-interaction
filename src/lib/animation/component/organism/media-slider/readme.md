# MediaSlider

Фотографии и видео переходят растворением: предыдущий слайд остаётся
непрозрачным под появляющимся новым, чтобы фон не мигал. Изображения
загружаются заранее; переход ждёт события загрузки следующего медиа.
Повторное переключение во время растворения выполняется после его завершения.

Длительность задаётся CSS-переменной `--c-media-slider-transition-duration`
на компоненте или его родителе, например `1200ms`. По умолчанию — `800ms`.
При `prefers-reduced-motion: reduce` переключение мгновенное.
В story есть настройка длительности и переключатель видеослайда.
